# CSCS 1240 Challenge Level 2054: Temperature Converter

## Challenge
Write a python script to accept a value from a file named "challenge.data" Assume the value represents a valid number. Write to a file named "challenge.out", a value representing the
input converted from Fahrenheit to Celsius or Celsius to Fahrenheit based upon a CLI
argument of "FtoC" or "CtoF". Define a functions named "FtoC" and "CtoF" to perform
the respective conversions. Call the functions passing only the value to be converted. 

## Requitements & Constraints
* **Input File** 'challeng.data' (assume numerical value)
* **Output File** 'challeng.out' (store the converted value)
* **Allowed import** 'sys'       ( sys argument )
* **Allowed builtins** 'open, float' (open file and float integer)
* **Allowed User defined functions** ("FtoC" or "CtoF".)
* **(2) functions one for "FtoC" and one for "CtoF"

## How to run
* ** CLI py chl2054.py FtoC
* ** CLI py chl2054.py CtoF
